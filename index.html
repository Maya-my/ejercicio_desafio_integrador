Integración numérica

Resuelve problemas de transporte, elasticidad, geometría, agua y energía usando trapecio compuesto, Simpson 1/3 y Simpson 3/8. Diseñada para practicar y verificar cálculos del desafío grupal de La Paz, Bolivia.

1. Configura el problema

Ingresa un par x,y por línea o usa un ejercicio de ejemplo.

Usa x como variable. Funciones disponibles: sin, cos, tan, exp, log, sqrt, abs, sinh, cosh, pi. Puedes escribir x^2.

Puedes editar los datos, seleccionar un método y calcular.

Los datos de los ejercicios son didácticos; no representan mediciones oficiales.

Gráfica de datos e integral

La curva une los puntos ingresados; el sombreado representa el área aproximada entre los límites. En datos tabulados, no se inventan puntos intermedios.

Fórmulas de referencia

Trapecio compuesto
T = h [(f₀ + fₙ)/2 + Σ fᵢ]
Simpson 1/3
S = (h/3) [f₀ + fₙ + 4Σ fᵢ impares + 2Σ fᵢ pares interiores]
Requiere n par.
Simpson 3/8
S = (3h/8) [f₀ + fₙ + 3Σ fᵢ no múltiplos de 3 + 2Σ fᵢ múltiplos de 3 interiores]
Requiere n múltiplo de 3.
h = (b − a)/n. Para datos tabulados, los valores de x deben estar igualmente espaciados. Error absoluto = |Iref − Iaprox|. Si no hay referencia conocida, el error verdadero no se puede calcular.

Verificación mínima de código

El ejercicio de prueba recomendado en la guía es integrar f(x) = x² entre 0 y 2. El valor exacto es 8/3 = 2.666666…. Selecciona la pestaña Función f(x), deja x², [0, 2] y prueba n=4 y n=8.
